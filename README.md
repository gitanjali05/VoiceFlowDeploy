# EmotionDetector

VoiceFlowDeploy (EmotionDetector) is a Flask web app that listens to a short voice recording, detects the speaker's emotion from both **tone of voice** and **spoken words**, and replies with an empathetic, spoken response generated by OpenAI — read back to the user with text-to-speech.

## How it works

1. **Record** — the browser records audio and sends it to the `/analyze` endpoint.
2. **Detect emotion** (`detect_emotion.py`) — combines two signals:
   - **Audio tone** via [emotion2vec](https://github.com/modelscope/FunASR) (through `funasr`)
   - **Spoken words** via OpenAI Whisper transcription + a text emotion classifier (`j-hartmann/emotion-english-distilroberta-base`)
   - Scores are fused (60% audio / 40% text), with a rule-based boost for angry/frustrated phrasing detected in the transcript.
   - If the local models can't run (e.g. on a constrained host like Render), `app.py` falls back to an OpenAI Whisper + GPT-based emotion classification.
3. **Generate a response** (`respond.py`) — sends the detected emotion, confidence, and transcript to an OpenAI model with a style-guide system prompt so the reply matches the emotion (calm for anger, gentle for sadness, upbeat for happiness, etc.).
4. **Speak the response** — `/tts` converts the generated text to speech using OpenAI's TTS (`tts-1`, `nova` voice) and streams back an MP3 for the browser to play.

The recognized emotions are: `angry`, `disgusted`, `fearful`, `happy`, `neutral`, `sad`, `surprised`.

## Project structure

| File | Purpose |
|---|---|
| `app.py` | Flask server — serves the frontend, `/analyze` (emotion + response), and `/tts` (speech synthesis) |
| `detect_emotion.py` | Audio + text emotion detection pipeline (emotion2vec, Whisper, text classifier) |
| `respond.py` | Builds the empathetic reply via the OpenAI Responses API and OpenAI TTS; also supports a terminal-based record/respond loop |
| `index.html` | Frontend UI for recording audio and playing back the response |
| `requirements.txt` | Python dependencies |
| `Procfile` | Deployment entry point (`gunicorn app:app`) |

## Getting started

### Prerequisites

- Python 3.9+
- An [OpenAI API key](https://platform.openai.com/api-keys)
- `ffmpeg` installed on your system (required by Whisper)

### Setup

```bash
git clone https://github.com/gitanjali05/VoiceFlowDeploy.git
cd VoiceFlowDeploy
python -m venv venv
source venv/bin/activate  # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in the project root:
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_RESPONSE_MODEL=gpt-4o

### Run locally

```bash
python app.py
```

The server starts on `http://localhost:5050` by default (or the port set by the `PORT` environment variable). Open that URL in a browser, allow microphone access, and start recording.

### Terminal mode

`respond.py` can also be run directly for a microphone-in/speaker-out loop (no browser needed):

```bash
python respond.py
```

Press **Enter** to start recording, and **Enter** again to stop; the detected emotion and generated reply are printed and spoken aloud via `afplay` (macOS).

## API endpoints

- `POST /analyze` — accepts an audio file (`multipart/form-data`, field name `audio`), returns:
```json
  {
    "emotion": "happy",
    "confidence": 0.87,
    "response": "Oh that's wonderful! I'm so glad to hear that."
  }
```
- `POST /tts` — accepts `{"text": "..."}`, returns an MP3 audio stream of the spoken text.

## Deployment

The included `Procfile` runs the app with Gunicorn, making it ready to deploy on platforms like Render or Heroku:
web: gunicorn app:app --bind 0.0.0.0:$PORT

Make sure to set the `OPENAI_API_KEY` environment variable in your deployment platform's dashboard. Note that the local audio-emotion models (Whisper, emotion2vec, transformers) are heavy — on memory-constrained hosts, `app.py` automatically falls back to a lighter OpenAI-based emotion classification if the local pipeline fails to load or run.

## Tech stack

- **Backend:** Flask, Flask-CORS, Gunicorn
- **Emotion detection:** FunASR (emotion2vec), OpenAI Whisper, Hugging Face Transformers
- **Language model:** OpenAI (GPT-4o via the Responses API)
- **Text-to-speech:** OpenAI TTS (`tts-1`)
